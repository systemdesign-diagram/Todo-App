# Architecture Decision Records

Approved Architecture Decision Records belong in this directory.

## Naming

Use sequential names such as:

- `0001-database-selection.md`
- `0002-authentication-strategy.md`

## Status values

- **Proposed** — under discussion; not approved.
- **Accepted** — approved by the project owner.
- **Rejected** — considered and not selected.
- **Superseded** — replaced by a later ADR.

Do not add a draft as an accepted decision. Keep a clear review and approval trail in the related GitHub issue or pull request.
